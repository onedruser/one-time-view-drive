# One-time View — starter project

Μικρή εφαρμογή για ανέβασμα αρχείων και link που εξυπηρετεί μία μόνο HTTP αίτηση προβολής.

## Τοπική εκκίνηση
Απαιτείται Docker:
```bash
docker compose up --build
```
Άνοιξε http://localhost:5000

## Τι περιλαμβάνει
- Τυχαία, μη προβλέψιμα tokens.
- Ατομική κατανάλωση token στη βάση SQLite (προστασία από δύο ταυτόχρονες χρήσεις).
- Λήξη link: 10 λεπτά, 1 ώρα, 24 ώρες ή 7 ημέρες.
- Διαγραφή του αρχείου μετά την εξυπηρέτηση της πρώτης προβολής.
- `Cache-Control: no-store` και περιορισμένη λίστα τύπων αρχείων.

## Πριν γίνει δημόσια χρήση
Αυτό είναι MVP/starter, όχι ελεγμένη υπηρεσία παραγωγής. Για δημόσια εγκατάσταση:
1. Χρησιμοποίησε hosting με HTTPS και **persistent disk/volume**. Χωρίς persistent storage, αρχεία/βάση μπορεί να χαθούν σε restart ή redeploy.
2. Κράτησε το `/data` σε ιδιωτικό persistent volume και περιόρισε την πρόσβαση σε αυτό.
3. Βάλε όριο ρυθμού (rate limiting), προστασία από κατάχρηση, monitoring και προγραμματισμένο καθαρισμό ληγμένων αρχείων/εγγραφών.
4. Πρόσθεσε κρυπτογράφηση αποθήκευσης και πολιτική απορρήτου πριν δεχτείς ευαίσθητα αρχεία.
5. Για production, χρησιμοποίησε managed database με συναλλαγές και object storage με ιδιωτικά αντικείμενα/διαγραφή.
6. Μην εκθέτεις το development server. Το Dockerfile χρησιμοποιεί Gunicorn.

## Σημαντικοί περιορισμοί
- Το «μία φορά» σημαίνει ότι ο server δέχεται μόνο μία πρώτη αίτηση. Preview scanners, antivirus ή αυτόματο link preview μπορεί να καταναλώσουν το link πριν το ανοίξει ο άνθρωπος.
- Δεν μπορεί να αποτραπεί screenshot, φωτογράφιση οθόνης, αντιγραφή ή αποθήκευση από τον παραλήπτη.
- Η διαγραφή μετά την απόκριση δεν εγγυάται διαγραφή αντιγράφων από backups, logs ή υποδομή hosting.
- Η προβολή PDF/εικόνων/κειμένου γίνεται από τον browser. Άλλοι τύποι αρχείων απορρίπτονται.
